# Qurani

**Content-focused Quran and Azkar application** with wide distribution, built to run well on lower-end devices and in multiple languages.

> **Showcase repository.** The production source code is private. This repository documents the product, its architecture and the engineering decisions behind it. Details and a walkthrough are available on request: mohammed.r.almekhafi@gmail.com

## Engineering highlights

- Small footprint and fast cold start on low-end Android devices.
- Multilingual content with RTL-first layouts.
- Firebase for messaging and remote configuration.

## Stack

`Flutter` · `Dart` · `Firebase` · `i18n`
